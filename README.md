Sales & Operations MIS Reporting Dashboard

Project Overview

An Excel-based MIS reporting project designed to monitor sales performance, order status, target achievement and regional and category-level sales.

Tools Used

- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Slicers and interactive filtering
- Data cleaning and KPI reporting

Key Features

- Sales & Operations dashboard
- Weekly sales reporting
- Region-wise sales analysis
- Product-category sales analysis
- Target achievement and pending-order tracking

Files Included

- Excel workbook with raw data and cleaned data
- Dashboard and supporting reports
- Dashboard screenshots

Dataset

Uses synthetic sample data for demonstration purposes.

Purpose

Created as a portfolio project to demonstrate practical Excel MIS reporting and dashboard development skills.
